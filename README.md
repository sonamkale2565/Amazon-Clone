# E-Shop – E-Commerce Website

## 📌 About Project

E-Shop is a responsive e-commerce website created using **HTML, CSS, and JavaScript**.
This project is designed for learning and demonstrating basic front-end web development skills.

## 🚀 Features

* Responsive design
* Product listing
* Product search functionality
* Add to Cart counter
* Navigation menu
* Hero section
* About and Contact sections
* Mobile-friendly layout

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Search and cart functionality
