# Amazon Clone

A frontend Amazon Clone website created for learning and practice purposes.

## About Project

This project is a static e-commerce website UI inspired by Amazon's layout.
It is developed using HTML and CSS to practice frontend web development skills.

## Technologies Used

- HTML5
- CSS3

## Features

- Amazon-like navigation bar
- Search bar design
- Product cards
- Product section
- Responsive layout
- Footer section

## Purpose

This project was created to improve my frontend development skills and understand website structure and styling.
